Code search that knows every file in your project.

FindWright gives Claude a code index that adapts to each project. It reads every file the project tracks, code, docs and config alike, and answers plain-English questions, names and regex searches with short answers that point at the right lines.

How Claude uses it

find
A plain-English question, a name, or both: the files that answer it, best first.
search
Regexes over every tracked file, with globs and context lines, like grep -n. Each hit names the function, heading or key around it.
symbols and outline
Names by kind, and one file's parts with their line ranges, so Claude reads only the part it needs.

Every call first re-reads the files that changed, so answers match the working tree. A file format no built-in extractor knows gets a pattern rule in the project's .findwright/config.json, and setup offers to write those rules for you.

Install

In a Claude Code session:

/plugin marketplace add starfoxcom/findwright
/plugin install findwright@findwright

Then run /findwright:setup. It installs FindWright's helper, the part that runs on your computer, after checking it against the SHA-256 the plugin pins, registers FindWright for every project, offers a hook that sends searches to it, and fits the index to the project you are in. It needs Node 22.16 or later (or Node 24 and up).

Privacy

FindWright sends nothing about you or your code. It downloads two things: the helper from its GitHub release, after your yes, and on the first search its meaning model (32 MB) from Hugging Face, checked against pinned SHA-256 sums. Setup and the doctor also read Node's public release list, to tell you when your Node is missing security fixes. Set FINDWRIGHT_MEANING=off to skip the model. The index stays in each project's .findwright/ folder, which keeps itself out of git.
