Why it exists

FindWright started because the search we used before kept falling short of the bar we set: at least 9 searches in 10 should name the file Claude opens next. Every miss means Claude searches again, and each extra search spends tokens the session could have spent on the change you asked for.

Search tools also tend to understand only the languages they ship support for, so a project outside that list falls back to plain text. FindWright doesn't follow that approach, since Claude tends to copy built-in support as it is instead of looking at the project in front of it.

So FindWright ships no languages at all. Claude reads your project and writes the rules that name its code, which makes a shader, a mod script or a config format nobody has heard of searchable by name like everything else.

    Install

    1. Open your project In the Code tab, start a new session in your project's folder.

    2. Install FindWright Paste this and send it, then wait until Claude says it is done.

      Install the FindWright plugin: run claude plugin marketplace add starfoxcom/wrights and then claude plugin install findwright@wrights in the shell. If claude is not found, add a marketplace named wrights with the GitHub source starfoxcom/wrights under extraKnownMarketplaces and "findwright@wrights": true under enabledPlugins in ~/.claude/settings.json, keeping the rest.

    3. Run the setup Start another new session in the same folder, so the plugin loads, and run this. It shows one plan of everything it will install and does it all on your yes. In your next projects, FindWright is already there.

      /findwright:setup

    1. On your computer, once Adds the wrights marketplace, then the plugin, for every project.

    What it needs

    Claude Code, and Node 22.16 or later, or Node 24 and up. Setup brings Node to its newest security patch: it installs it on Windows and hands you the installer elsewhere.

    What it downloads

    During setup, its helper from the GitHub release and a 32 MB meaning model from Hugging Face, both checked against pinned checksums. Setup and the doctor also read Node's public release list, and on Windows setup installs Node through winget.

    What stays on your computer

    Your code, queries and file names. Each project's index lives in its own .findwright folder, which keeps itself out of git. If you turn on the anonymous usage counts, a project sends four daily sums about its searches and the time span they cover, under a random id and the kind you pick, and the counter keeps the country it reads from the connection.
