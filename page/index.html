Install

  1. Open your project In the Code tab, start a new session in your project's folder.

  2. Install FindWright Paste this and send it, then wait until Claude says it is done.

    Install the FindWright plugin: run claude plugin marketplace add starfoxcom/findwright and then claude plugin install findwright@findwright in the shell. If claude is not found, add a marketplace named findwright with the GitHub source starfoxcom/findwright under extraKnownMarketplaces and "findwright@findwright": true under enabledPlugins in ~/.claude/settings.json, keeping the rest.

  3. Run the setup Start another new session in the same folder, so the plugin loads, and run this. In your next projects, FindWright is already there.

    /findwright:setup

  1. On your computer, once Adds the FindWright marketplace, then the plugin, for every project.

    /plugin marketplace add starfoxcom/findwright
    /plugin install findwright@findwright

  2. Run the setup It installs what FindWright needs and asks only about the search hook and fitting the index to your project. In your next projects, FindWright is already there.

    /findwright:setup

What it needs

Claude Code, and Node 22.16 or later, or Node 24 and up. Setup brings Node to its newest security patch: it installs it on Windows and hands you the installer elsewhere.

What it downloads

During setup, its helper from the GitHub release and a 32 MB meaning model from Hugging Face, both checked against pinned checksums. Setup and the doctor also read Node's public release list, and on Windows setup installs Node through winget.

What stays on your computer

Your code, queries and file names. Each project's index lives in its own .findwright folder, which keeps itself out of git. If you turn on the anonymous usage counts, a project sends four daily sums about its searches and the time span they cover, under a random id and the kind you pick, and the counter keeps the country it reads from the connection.
