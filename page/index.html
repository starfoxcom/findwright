Claude finds the right file on the first search

FindWright gives Claude an index of every file in your project, so a question in plain words comes back as the few files that answer it, in milliseconds.

Install FindWright Read the source

What changes

  • Claude searches again and again, one guess at a time It asks once and gets the files that answer A question in plain words, a name, or both, comes back as the files that answer it, best first.
  • Long search results fill up the session Short answers leave room for the work The typical answer is a few lines that point at the right place, so more of each session goes to the change you asked for.
  • Docs and settings get left out of the search Every file the project tracks is searched Code, docs, config and templates sit in the same index, so the answer can be a guide as easily as a function.
  • The index falls behind your edits Answers match your files as they are now Each search first takes in the files that changed, so there is nothing to refresh by hand.

    How Claude uses it

    • Find A plain-English question, a name, or both: the files that answer it, best first.
    • Search Patterns over every tracked file, with the lines around each hit and the function, heading or key it sits in.
    • Symbols and outline Names by kind, and one file's parts with their line ranges, so Claude reads only the part it needs.
    • Fits each project A file type no built-in reader knows gets a pattern rule in the project's settings, and setup offers to write those rules for you.

    Install

    1. On your computer, once Adds the FindWright marketplace, then the plugin, for every project.

      /plugin marketplace add starfoxcom/findwright
      /plugin install findwright@findwright

    2. Then run the setup It installs the part that runs on your computer after checking it against the plugin's pinned checksum, and changes nothing without your yes. It needs Node 22.16 or later, or Node 24 and up.

      /findwright:setup

    1. Open your project In the Code tab, start a new session in your project's folder.

    2. Install FindWright Paste this and send it, then wait until Claude says it is done.

      Install the FindWright plugin: run claude plugin marketplace add starfoxcom/findwright and then claude plugin install findwright@findwright in the shell. If claude is not found, add a marketplace named findwright with the GitHub source starfoxcom/findwright under extraKnownMarketplaces and "findwright@findwright": true under enabledPlugins in ~/.claude/settings.json, keeping the rest.

    3. Run the setup Start another new session in the same folder, so the plugin loads, and run this.

      /findwright:setup

    Privacy

    FindWright sends nothing about you or your code. It downloads two things: its helper from the GitHub release, after your yes, and on the first search a 32 MB meaning model from Hugging Face, both checked against pinned checksums. Setup and the doctor also read Node's public release list, to tell you when your Node is missing security fixes. Set FINDWRIGHT_MEANING=off to skip the model. The index stays in each project's .findwright/ folder, which keeps itself out of git.
